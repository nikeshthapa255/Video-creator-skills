# Failure-to-fix playbook

Map each QA failure code to the cheapest reliable fix across Mode A (Gemini Omni 1.2 Flash) and Mode B (Keyframe + Motion). Append newly discovered fixes after production runs.

| Failure code | First-choice fix | Fallback fix |
| :--- | :--- | :--- |
| `HOOK_WEAK` | Mode A: Trim static lead-in or edit via `--previous-interaction-id` (`"Show [landmark] clearly behind the character from frame 1. Keep everything else the same."`). Mode B: Switch Shot 1 to `whip_zoom` or `bounce_pop` with `--flash-in` and open on a high-contrast visual gag. | Rewrite Shot 1 beat `[0-2s]` with an active camera push-in and immediate character motion. |
| `EXTRA_LIMB` | Mode A: Edit in place via `--previous-interaction-id`: `"Remove the extra hand on [character]; keep exactly two arms. Keep everything else the same."` Mode B: Re-roll the keyframe with a simpler arm pose. | Remove held objects from the beat or avoid extreme side-profile turns. |
| `STYLE_DRIFT` | Re-anchor with the original 3-panel turnaround sheet (do not chain a drifted frame) and verify the verbatim `style_bible` block is present. | Shorten the clip (2.5-7s) and lock `"In a single unbroken scene, no scene cuts"`. |
| `MULTI_CHAR_BLEED` | Split into shot-reverse-shot (one character per cut) or pin positions (`"Character A on screen left, Character B on screen right, separated by a desk"`). | Pass distinct turnaround sheets for both characters in explicit upload order. |
| `TEXT_WARP` | Replace prompt wording with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage, no watermarks"` (plus local script guards like `"plain silk banners, plain scrolls, zero Chinese characters"` in historical settings), swap any flagged text-magnet props using the Text-Magnet Prop Substitution Table in `references/sheet_prompt_templates.md`, and render all text via FFmpeg/ASS. | Crop or re-frame away from the background edge artifact during composition. |
| `LITERAL_BLANK_SIGN` | Strip `"blank signs"` or `"empty billboards"` from `style_bible` and shot prompts (caught as a hard error by `--lint-plan`; they trigger literal `"BLANK"` or `"ADSPACE AVAILABLE"` text). Replace with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage"` and re-roll the shot. | Replace storefronts or trucks in the shot description with natural or architectural backdrops (brick wall, glass atrium, palm trees, skyline). |
| `STATE_CONTINUITY_DRIFT` | Generate a dedicated state-variant 3-panel turnaround sheet (Template 1D, e.g., `sheets/hero_veiled.png` vs `sheets/hero.png`), map it under `characters[].state_sheets`, set `shots[].character_states`, and flip `negative_constraints` at the exact transition shot. Re-roll only the affected shots with `animate_shot_v2.py --shot-ids <csv>`. | Document progressive damage (stained cuff, removed hairpins, injuries) in `characters[].continuity_notes` and enforce it explicitly in every downstream shot prompt. |
| `LOCATION_CONTINUITY_DRIFT` | Generate an empty-set master location plate (Template 1E, `sheets/loc_<id>.png`), register it in `locations[]` with locked key-light direction, and attach it as `Image 2` alongside the character sheet in Stage 3. | Lock exact architectural landmarks and lighting color temperature inside `acts[].lighting_mood` and `style_bible`. |
| `EYELINE_CROSS` | Set explicit opposing `eyeline` (`screen_right` vs `screen_left`) and `focal_anchor` (`left_third` vs `right_third`) on shot-reverse-shot dialogue pairs and re-roll the flipped keyframe. | Insert a neutral cutaway/prop insert (`shot_role: "insert"`) or a left/right two-shot to reset screen geography cleanly. |
| `TTS_MISREAD` | Run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json`. Keep clean display text (`AWS`, `NPCs`, `GTA 6`, `Pei Xuan`, `911`, `$75,000`, `Nov 24`) in `dialogue_or_vo`, avoid compact currency (`$1.5T`), spaced phonetic leaks (`N P C`), and risky ALL-CAPS 2-letter words (`US`, `IT`, `IN`, `OR`, `AM`), and put phonetic fixes in `tts_pronunciations` or `tts_text`. Re-synthesize VO and re-assemble. | Switch voice (`AvaNeural`, `EmmaNeural`, `SoniaNeural`, `RyanNeural`) or add a comma/hyphen pause in `tts_text` for tricky names or homographs, then verify with audio via `view_file`. |
| `VOICE_CAST_DRIFT` | Define one canonical top-level `voice_cast` (drop any legacy `speaker_voices` block) using `WordBoundary`-verified voices (`en-GB-SoniaNeural`, `en-US-AvaNeural`, `en-GB-RyanNeural`, `en-US-EmmaNeural`, `en-GB-ThomasNeural`). Calibrate rates (`+13%` to `+18%` for 5-min `9:16` drama; `+6%` to `+10%` for `16:9` commentary) and re-run `tts_and_captions_v2.py --concurrency 4 --max-retries 4`. | Override a single mistimed line via per-shot `rate`/`pitch`/`post_gap_sec`, then re-run `animate_shot_v2.py` for affected shots (re-render downstream clips if timing shifts noticeably). |
| `AI_SLOP_SCRIPT` | Open [spoken_english_guide.md](./spoken_english_guide.md) and rewrite flagged lines in `shot_plan.json` (and YouTube metadata) before Stage 2 TTS. Set `"script_genre": "drama"` for scripted fiction so valid character dialogue is not over-flagged while commentary hosts stay enforced. Re-run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json --strict-slop` and `--lint-metadata packaging.md --strict-slop`. | Read each Act aloud. Cut any line you would not say to a friend, mix quick punchlines with fuller setups, keep natural contractions, and replace visual double-narration with silent reaction beats (`dialogue_or_vo: ""`). |
| `CAPTION_OVERLAP` | Regenerate captions with `tts_and_captions_v2.py` (exact `WordBoundary` clamping) or `srt_to_ass.py` (`next_start - 0.01s` clamping) so `assemble_short.sh`'s overlap assertion passes. | Inspect offending timestamps printed by `assemble_short.sh` and adjust overlapping SRT cue boundaries before regenerating `.ass`. |
| `CAPTION_CLIP_HORIZONTAL` | On `9:16`, regenerate with `--font-size 86 --max-chars 18 --margin-v 420`. On `16:9`, regenerate with `--aspect-ratio 16:9 --caption-style clean_subtitle --font-size 62 --max-chars 36 --margin-v 116 --tilt 0` (or use `caption_style: "none"` + `captions.srt`). | Split long compound phrases or hyphenated words in `shot_plan.json` dialogue (or lower `--font-size` slightly) so no line exceeds the width cap, then regenerate captions. |
| `AUDIO_DESYNC` | Switch to **audio-first timing**: run `tts_and_captions_v2.py` first to generate `shot_timings.json`, then animate every Mode B shot to its exact spoken duration (`animate_shot_v2.py --timings`). For Hybrid Mode A clips, strip audio (`-an`) and trim to `shot_timings.json` `duration_sec`. | Trim or pad clip boundaries by 0.05-0.15s before concat, and inspect `f_frame0.png` + `f_end.png` via `extract_qa_frames.sh`. |
| `FRAME_TIMELINE_DRIFT` | Always render parallel long-form slices with `animate_shot_v2.py --timings audio/shot_timings.json --act <N>` (plus `--skip-omni` in hybrid mode), which computes global cumulative frame counts across ALL shots before slicing (`<= 1` frame drift over 5+ min). | Re-render drifted Acts using `--act <N>` without `--skip-existing` and re-assemble with `assemble_short.sh`. |
| `OFF_MODEL_CHARACTER` / `LIKENESS_DRIFT` | 1) Run Stage 0 `python3 scripts/research_characters.py --entities "..."` (or `--user-ref <id>=<local_image_path>`). 2) Inspect every portrait in `uninspected_entities` with `read_file` and lock traits via `--verify <id> --traits "..."`. 3) Regenerate the 3-panel sheet using Template 1B (mascot) or 1C (real person), check it side by side, and re-anchor Stage 3 shots to it. | If photo-to-image hits a celebrity filter, inspect the Stage 0 portrait and list observable traits (hairline, hair color, glasses, face shape, age, signature outfit) in Template 1C without uploading the raw photo. Verify the 3-panel sheet side by side, then pass only that sheet to Stage 3. |
| `SOLO_CHAR_BLEED` | Prepend the solo-character override clause to the shot prompt (`"SOLO character: ONLY <char> appears in this frame; no other named characters, mascots, or co-hosts appear in the foreground"`) and pass only that character's turnaround sheet in the reference image array. | Remove any mention of secondary characters or channel hosts from `style_bible` (keep `style_bible` to rendering, lighting, and framing) and re-roll the shot. |
| `BGM_OVERPOWERS_VO` | Re-run assembly with `SHORTS_VO_CLARITY=1 SHORTS_BGM_GAIN_DB=-15 bash scripts/assemble_short.sh ...` (or `-18` / `-20 dB` for dense tracks). This enables vocal clarity EQ, single-point `-3.0 dB @ 2.9 kHz` speech carving, and smooth musical sidechain ducking under VO. | Swap to a sparser instrumental track or add `bgm_cue: "drop_out"` on critical dialogue lines and re-verify with audio. |
| `BGM_TONE_MISMATCH` | Replace quirky or arcade BGM with a genre-matched dramatic instrumental: run `python3 scripts/retrieve_music.py --mood dramatic_news --duration <sec> --out audio/bgm.wav` (or `--mood cinematic_tension`) and re-assemble. | If offline or no retrieved track fits, synthesize a dark news, tension, or multi-act dramatic bed via `python3 scripts/make_bgm.py --mood dramatic_news` (or `palace_drama` / `epic_story`) and re-assemble. |
| `SFX_TONE_MISMATCH` | Replace cartoon SFX (`bonk_boing`, `pop`, `record_scratch`, `siren_chirp`) in `16:9` commentary plans with soft-calibrated Tech/UI editorial cues (`ui_tick`, `ui_click`, `data_chime`, `sub_whoosh`, `alert_ping`, `soft_thud`), set `ambience_bed: "newsroom_air"`, and re-run `sfx_engine.py --timings audio/shot_timings.json --out audio/sfx_track.wav`. | Lower `sfx_gain_db` to `-6.0` on busy transition cuts or switch non-essential cues to `"none"` so narration stays clean. |
| `ACT_BGM_FATIGUE` | Replace a short looped track with an Act-aware multi-act score locked to `shot_timings.json`: run `python3 scripts/make_bgm.py --mood palace_drama --timings audio/shot_timings.json --out audio/bgm.wav` (or `--mood epic_story`), set `acts[].bgm_intensity` per Act, and use `shots[].bgm_cue` for spotted silence. | Split BGM per Act using distinct mood cues and crossfade at `acts[].start_sec` boundaries before assembly. |
| `IMAGE_QUOTA_EXHAUSTED` | Stop further image calls for the current wave, keep all finished `scenes/<shot_id>.png` files on disk, and record `quota_paused (N/M keyframes)` in the production log. Finish all zero-quota work (Stage 1 plans, audio stems, `packaging.md`) across remaining topics first, then resume only missing keyframes in Wave 2 (cap waves at 3 to 4 Shorts per quota window; see `references/batch_and_delivery.md`). | Reuse approved establishing/studio plates or switch dense stat beats to dark-mode big-type data slides (`motion_preset: "static_hold"`) so fewer fresh AI images are required per episode. |
| `QA_FILE_TOO_LARGE` | Slice the finished long-form MP4 into lossless 60-second review segments (`< 100 MB` each) plus 10 keyframe screenshots, per-segment LUFS, and `chapters.txt`: `bash scripts/split_qa_segments.sh final_episode.mp4 qa_segments --timings audio/shot_timings.json`. Inspect every `qa_min*.mp4` chunk with sound via `view_file`. | Pass `--segment-sec 45` if a high-bitrate `16:9` chunk approaches `100 MB`. |
