# Failure-to-fix playbook

Map each QA failure code to the cheapest reliable fix across Mode A (Gemini Omni 1.2 Flash) and Mode B (Keyframe + Motion). Append newly discovered fixes after production runs.

| Failure code | First-choice fix | Fallback fix |
| :--- | :--- | :--- |
| `HOOK_WEAK` | Mode A: Trim static lead-in or edit via `--previous-interaction-id` (`"Show [landmark] clearly behind the character from frame 1. Keep everything else the same."`). Mode B: Switch Shot 1 to `whip_zoom` or `bounce_pop` with `--flash-in` and open on a high-contrast visual gag. | Rewrite Shot 1 beat `[0-2s]` with an active camera push-in and immediate character motion. |
| `EXTRA_LIMB` | Mode A: Edit in place via `--previous-interaction-id`: `"Remove the extra hand on [character]; keep exactly two arms. Keep everything else the same."` Mode B: Re-roll the keyframe with a simpler arm pose. | Remove held objects from the beat or avoid extreme side-profile turns. |
| `STYLE_DRIFT` | Re-anchor with the original 3-panel turnaround sheet (do not chain a drifted frame) and verify the verbatim `style_bible` block is present. | Shorten the clip (2.5-7s) and lock `"In a single unbroken scene, no scene cuts"`. |
| `MULTI_CHAR_BLEED` | Split into shot-reverse-shot (one character per cut) or pin positions (`"Character A on screen left, Character B on screen right, separated by a desk"`). | Pass distinct turnaround sheets for both characters in explicit upload order. |
| `TEXT_WARP` | Replace prompt wording with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage, no watermarks"` and render all text via FFmpeg/ASS. | Crop or re-frame away from the background edge artifact during 9:16 composition. |
| `LITERAL_BLANK_SIGN` | Strip `"blank signs"` or `"empty billboards"` from `style_bible` and shot prompts (they trigger literal `"BLANK"` or `"ADSPACE AVAILABLE"` text). Replace with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage"` and re-roll the shot. | Replace storefronts or trucks in the shot description with natural or architectural backdrops (brick wall, glass atrium, palm trees, skyline). |
| `TTS_MISREAD` | Run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json`. Keep clean display text (`AWS`, `GTA 6`, `911`, `$75,000`, `Nov 24`) in `dialogue_or_vo`, and put phonetic fixes (`"AWS": "A W S"`, `"$700 PS5 Pro": "700-dollar PS5 Pro"`, `"no 60 FPS": "no sixty FPS"`, `"911": "nine-one-one"`) in top-level `tts_pronunciations` or per-shot `tts_text` so captions never break. Re-synthesize VO and re-assemble. | Switch voice (`AvaNeural`, `EmmaNeural`, `JennyNeural`) or add a comma or hyphen pause in `tts_text` for tricky compound terms, then verify by watching `final_short.mp4` with audio via `read_file`. |
| `AI_SLOP_SCRIPT` | Open [spoken_english_guide.md](./spoken_english_guide.md) and rewrite flagged lines in `shot_plan.json` (and YouTube metadata) before Stage 2 TTS. Fix dropped grammar, vary shot length, ground unfamiliar names with roles, and replace dead openers, fake contrasts (`"not just X, it's Y"`, `"Forget X — Y"`), colon reveals (`"Plot twist:"`, `"Here's the catch:"`), dramatic fragments, trailing `"-ing"` riders, buzzwords, and flat `"Which is why..."` endings with plain active speech. Re-run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json --strict-slop`. | Read the script aloud in 35 to 40 seconds. Cut any line you would not say to a friend, mix quick 4-7 word punchlines with 12-16 word setups, keep natural contractions, and replace any moral wrap-up with a direct callback or visual loop into Shot 1. |
| `CAPTION_OVERLAP` | Regenerate captions with `tts_and_captions_v2.py` (exact `WordBoundary` clamping) or `srt_to_ass.py` (`next_start - 0.01s` clamping) so `assemble_short.sh`'s overlap assertion passes. | Inspect offending timestamps printed by `assemble_short.sh` and adjust overlapping SRT cue boundaries before regenerating `.ass`. |
| `CAPTION_CLIP_HORIZONTAL` | Regenerate captions with `--font-size 86 --max-chars 18 --margin-v 420 --keyword-color auto` (via `tts_and_captions_v2.py --caption-style kinetic_keyword` or `srt_to_ass.py`). This keeps ~45-50px side margins at `126%` pop and `+/-2.5 deg` tilt. | Split long compound phrases or hyphenated words in `shot_plan.json` dialogue (or lower `--font-size` slightly) so no line exceeds `18-20` characters, then regenerate captions. |
| `AUDIO_DESYNC` | Switch to **audio-first timing**: run `tts_and_captions_v2.py` first to generate `shot_timings.json`, then animate every Mode B shot to its exact spoken duration (`animate_shot_v2.py --timings`). For Mode A native audio, re-run edit with `--strip-audio`. | Trim or pad clip boundaries by 0.05-0.15s before concat, and inspect `f_end.png` via `extract_qa_frames.sh` (uses video-stream duration + `-sseof`). |
| `OFF_MODEL_CHARACTER` / `LIKENESS_DRIFT` | 1) Run Stage 0 `python3 scripts/research_characters.py --entities "..."` (or `--user-ref <id>=<local_image_path>`). 2) Inspect the reference image with `read_file`. 3) Regenerate the 3-panel sheet using Template 1B (mascot) or 1C (real person), check it side by side, and re-anchor Stage 3 shots to it. | If photo-to-image hits a celebrity filter, inspect the Stage 0 portrait and list observable traits (hairline, hair color, glasses, face shape, age, signature outfit) in Template 1C without uploading the raw photo. Verify the 3-panel sheet side by side, then pass only that sheet to Stage 3. |
| `SOLO_CHAR_BLEED` | Prepend the solo-character override clause to the shot prompt (`"SOLO character: ONLY <char> appears in this frame; no other characters, mascots, or co-hosts appear anywhere in the scene"`) and pass only that character's turnaround sheet in the reference image array. | Remove any mention of secondary characters or channel hosts from `style_bible` (keep `style_bible` to rendering, lighting, and framing) and re-roll the shot. |
| `BGM_OVERPOWERS_VO` | Re-run assembly with `SHORTS_VO_CLARITY=1 SHORTS_BGM_GAIN_DB=-16 bash scripts/assemble_short.sh ...` (or `-18` / `-20 dB` for dense tracks). This enables vocal clarity EQ, a 2-4 kHz speech-band carve, and sidechain ducking under VO. | Swap to a sparser instrumental track with fewer mid-range lead melodies (via `retrieve_music.py` or `make_bgm.py`) and re-verify by watching `final_short.mp4` with audio. |
| `BGM_TONE_MISMATCH` | Replace quirky or arcade BGM with a genre-matched dramatic instrumental: run `python3 scripts/retrieve_music.py --mood dramatic_news --duration <sec> --out audio/bgm.wav` (or `--mood cinematic_tension`) and re-assemble. | If offline or no retrieved track fits, synthesize a dark news or tension bed via `python3 scripts/make_bgm.py --mood dramatic_news` (or `--mood cinematic_tension`) and re-assemble with `SHORTS_BGM_GAIN_DB=-16`. |
