# Failure-to-fix playbook

Map each QA failure code to the cheapest reliable fix across Mode A (Gemini Omni 1.2 Flash) and Mode B (Keyframe + Motion). Append newly discovered fixes after production runs.

| Failure code | First-choice fix | Fallback fix |
| :--- | :--- | :--- |
| `HOOK_WEAK` | Mode A: Trim static lead-in or edit via `--previous-interaction-id` (`"Show [landmark] clearly behind the character from frame 1. Keep everything else the same."`). Mode B: Switch Shot 1 to `whip_zoom` or `bounce_pop` with `--flash-in` and open on a high-contrast visual gag. | Rewrite Shot 1 beat `[0-2s]` with an active camera push-in and immediate character motion. |
| `EXTRA_LIMB` | Mode A: Edit in place via `--previous-interaction-id`: `"Remove the extra hand on [character]; keep exactly two arms. Keep everything else the same."` Mode B: Re-roll the keyframe with a simpler arm pose. | Remove held objects from the beat or avoid extreme side-profile turns. |
| `STYLE_DRIFT` | Re-anchor with the original 3-panel turnaround sheet (do not chain a drifted frame) and verify the verbatim `style_bible` block is present. | Shorten the clip (2.5-7s) and lock `"In a single unbroken scene, no scene cuts"`. |
| `MULTI_CHAR_BLEED` | Split into shot-reverse-shot (one character per cut) or pin positions (`"Character A on screen left, Character B on screen right, separated by a desk"`). | Pass distinct turnaround sheets for both characters in explicit upload order. |
| `TEXT_WARP` | Replace prompt wording with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage, no watermarks"` (and add local script guards like `"plain silk banners, plain scrolls, zero Chinese characters"` in historical settings) and render all text via FFmpeg/ASS. | Crop or re-frame away from the background edge artifact during composition. |
| `LITERAL_BLANK_SIGN` | Strip `"blank signs"` or `"empty billboards"` from `style_bible` and shot prompts (they trigger literal `"BLANK"` or `"ADSPACE AVAILABLE"` text). Replace with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage"` and re-roll the shot. | Replace storefronts or trucks in the shot description with natural or architectural backdrops (brick wall, glass atrium, palm trees, skyline). |
| `STATE_CONTINUITY_DRIFT` | Generate a dedicated state-variant 3-panel turnaround sheet (Template 1D, e.g., `sheets/hero_veiled.png` vs `sheets/hero.png`), map it under `characters[].state_sheets`, set `shots[].character_states`, and flip `negative_constraints` at the exact transition shot. Re-roll only the affected shots with `animate_shot_v2.py --shot-ids <csv>`. | Document progressive damage (stained cuff, removed hairpins, injuries) in `characters[].continuity_notes` and enforce it explicitly in every downstream shot prompt. |
| `TTS_MISREAD` | Run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json`. Keep clean display text (`AWS`, `GTA 6`, `Pei Xuan`, `911`, `$75,000`, `Nov 24`) in `dialogue_or_vo`, and put phonetic fixes (`"AWS": "A W S"`, `"Pei Xuan": "Pay Shwen"`, `"$700 PS5 Pro": "700-dollar PS5 Pro"`, `"911": "nine-one-one"`) in top-level `tts_pronunciations` or per-shot `tts_text` so captions never break. Re-synthesize VO and re-assemble. | Switch voice (`AvaNeural`, `EmmaNeural`, `SoniaNeural`, `RyanNeural`) or add a comma or hyphen pause in `tts_text` for tricky names or compound terms, then verify with audio via `view_file`. |
| `VOICE_CAST_DRIFT` | Define one canonical top-level `voice_cast` (drop any legacy `speaker_voices` block) using `WordBoundary`-verified voices (`en-GB-SoniaNeural`, `en-US-AvaNeural`, `en-GB-RyanNeural`, `en-US-EmmaNeural`, `en-GB-ThomasNeural`). Calibrate rates (`+13%` to `+18%` with `--gap 0.08` and `post_gap_sec: 0.25` on Act breaks for 5-min drama) and re-run `tts_and_captions_v2.py --concurrency 4 --max-retries 4`. | Override a single mistimed line via per-shot `rate`/`pitch`/`post_gap_sec`, then re-run `animate_shot_v2.py` with `--skip-existing` removed only for changed shots. |
| `AI_SLOP_SCRIPT` | Open [spoken_english_guide.md](./spoken_english_guide.md) and rewrite flagged lines in `shot_plan.json` (and YouTube metadata) before Stage 2 TTS. Fix dropped grammar, vary shot length, ground unfamiliar names with roles, and replace dead openers, fake contrasts (`"not just X, it's Y"`, `"Forget X — Y"`), colon reveals (`"Plot twist:"`, `"Here's the catch:"`), dramatic fragments, trailing `"-ing"` riders, buzzwords, and flat `"Which is why..."` endings with plain active speech. Re-run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json --strict-slop`. | Read each Act aloud. Cut any line you would not say to a friend, mix quick 4-7 word punchlines with 12-16 word setups, keep natural contractions, and replace moral lectures with concrete action or dialogue. |
| `CAPTION_OVERLAP` | Regenerate captions with `tts_and_captions_v2.py` (exact `WordBoundary` clamping) or `srt_to_ass.py` (`next_start - 0.01s` clamping) so `assemble_short.sh`'s overlap assertion passes. | Inspect offending timestamps printed by `assemble_short.sh` and adjust overlapping SRT cue boundaries before regenerating `.ass`. |
| `CAPTION_CLIP_HORIZONTAL` | On `9:16`, regenerate with `--font-size 86 --max-chars 18 --margin-v 420`. On `16:9`, regenerate with `--aspect-ratio 16:9 --font-size 62 --max-chars 36 --margin-v 72 --tilt 0`. | Split long compound phrases or hyphenated words in `shot_plan.json` dialogue (or lower `--font-size` slightly) so no line exceeds the width cap, then regenerate captions. |
| `AUDIO_DESYNC` | Switch to **audio-first timing**: run `tts_and_captions_v2.py` first to generate `shot_timings.json`, then animate every Mode B shot to its exact spoken duration (`animate_shot_v2.py --timings`). For Mode A native audio, re-run edit with `--strip-audio`. | Trim or pad clip boundaries by 0.05-0.15s before concat, and inspect `f_end.png` via `extract_qa_frames.sh` (uses video-stream duration + `-sseof`). |
| `FRAME_TIMELINE_DRIFT` | Always render parallel long-form slices with `animate_shot_v2.py --timings audio/shot_timings.json --act <N>` (or `--start-idx`/`--end-idx`), which computes global cumulative frame counts across ALL shots before slicing (`<= 1` frame drift over 5+ min). | Re-render drifted Acts using `--act <N>` without `--skip-existing` and re-assemble with fast-path `assemble_short.sh`. |
| `OFF_MODEL_CHARACTER` / `LIKENESS_DRIFT` | 1) Run Stage 0 `python3 scripts/research_characters.py --entities "..."` (or `--user-ref <id>=<local_image_path>`). 2) Inspect the reference image with `read_file`. 3) Regenerate the 3-panel sheet using Template 1B (mascot) or 1C (real person), check it side by side, and re-anchor Stage 3 shots to it. | If photo-to-image hits a celebrity filter, inspect the Stage 0 portrait and list observable traits (hairline, hair color, glasses, face shape, age, signature outfit) in Template 1C without uploading the raw photo. Verify the 3-panel sheet side by side, then pass only that sheet to Stage 3. |
| `SOLO_CHAR_BLEED` | Prepend the solo-character override clause to the shot prompt (`"SOLO character: ONLY <char> appears in this frame; no other characters, mascots, or co-hosts appear anywhere in the scene"`) and pass only that character's turnaround sheet in the reference image array. | Remove any mention of secondary characters or channel hosts from `style_bible` (keep `style_bible` to rendering, lighting, and framing) and re-roll the shot. |
| `BGM_OVERPOWERS_VO` | Re-run assembly with `SHORTS_VO_CLARITY=1 SHORTS_BGM_GAIN_DB=-16 bash scripts/assemble_short.sh ...` (or `-18` / `-20 dB` for dense tracks). This enables vocal clarity EQ, a `-3.5 dB` speech-band carve at `2.8 kHz`, and sidechain ducking under VO. | Swap to a sparser instrumental track or regenerate with `make_bgm.py --timings` (which includes speech-pocket FFT EQ) and re-verify with audio. |
| `BGM_TONE_MISMATCH` | Replace quirky or arcade BGM with a genre-matched dramatic instrumental: run `python3 scripts/retrieve_music.py --mood dramatic_news --duration <sec> --out audio/bgm.wav` (or `--mood cinematic_tension`) and re-assemble. | If offline or no retrieved track fits, synthesize a dark news, tension, or multi-act dramatic bed via `python3 scripts/make_bgm.py --mood dramatic_news` (or `palace_drama` / `epic_story`) and re-assemble with `SHORTS_BGM_GAIN_DB=-16`. |
| `ACT_BGM_FATIGUE` | Replace a short looped track with an Act-aware multi-act score locked to `shot_timings.json`: run `python3 scripts/make_bgm.py --mood palace_drama --timings audio/shot_timings.json --out audio/bgm.wav` (or `--mood epic_story`) so orchestration evolves across every Act and resolves in the epilogue. | Split BGM per Act using distinct mood cues and crossfade at `acts[].start_sec` boundaries before assembly. |
| `QA_FILE_TOO_LARGE` | Slice the finished long-form MP4 into lossless 60-second review segments (`< 60 MB` each) plus 10 keyframe screenshots and a LUFS audit: `bash scripts/split_qa_segments.sh final_episode.mp4 qa_segments --timings audio/shot_timings.json`. Inspect every `qa_min*.mp4` chunk with sound via `view_file`. | Pass `--segment-sec 45` if a high-bitrate `16:9` chunk still approaches `100 MB`. |
