# Failure-to-Fix Playbook (Evolutionary Memory)

Map each QA failure code to the cheapest reliable fix across Mode A (Gemini Omni 1.2 Flash) and Mode B (Keyframe + Motion). Append newly discovered fixes after production runs.

| Failure Code | First-Choice Fix | Fallback Fix |
| :--- | :--- | :--- |
| `HOOK_WEAK` | Mode A: Trim static lead-in or edit via `--previous-interaction-id` (`"Show [landmark] clearly behind the character from frame 1. Keep everything else the same."`). Mode B: Switch Shot 1 to `whip_zoom` or `bounce_pop` with `--flash-in` and open on a high-contrast visual gag. | Rewrite Shot 1 beat `[0-2s]` with an active camera push-in and immediate character motion. |
| `EXTRA_LIMB` | Mode A: Edit in place via `--previous-interaction-id`: `"Remove the extra hand on [character]; keep exactly two arms. Keep everything else the same."` Mode B: Re-roll keyframe with simpler arm pose. | Remove held objects from the beat or avoid extreme side-profile turns. |
| `STYLE_DRIFT` | Re-anchor with the original 3-panel turnaround sheet (do not chain a drifted frame) and verify the verbatim `style_bible` block is present. | Shorten the clip (2.5-7s) and lock `"In a single unbroken scene, no scene cuts"`. |
| `MULTI_CHAR_BLEED` | Split into shot-reverse-shot (one character per cut) or explicitly pin positions (`"Character A on screen left, Character B on screen right, separated by a desk"`). | Pass distinct turnaround sheets for both characters in explicit upload order. |
| `TEXT_WARP` | Replace prompt wording with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage, no watermarks"` and render all text via FFmpeg/ASS. | Crop or re-frame away from the background edge artifact during 9:16 composition. |
| `LITERAL_BLANK_SIGN` | Strip `"blank signs"` or `"empty billboards"` from `style_bible` and shot prompts (they trigger literal `"BLANK"` or `"ADSPACE AVAILABLE"` text). Replace with `"unadorned facades, plain empty surfaces, zero letters, zero digits, zero signage"` and re-roll the shot. | Replace storefronts/trucks in the shot description with natural or architectural backdrops (brick wall, glass atrium, palm trees, skyline). |
| `TTS_MISREAD` | Run `python3 scripts/tts_and_captions_v2.py --lint-plan shot_plan.json`. Rewrite `$700 PS5 Pro` -> `700-dollar PS5 Pro`, `no 60 FPS` -> `no sixty FPS` (or `zero 60 FPS`), and spell out ambiguous numbers/abbreviations; re-synthesize VO and re-assemble. | Switch voice (`AvaNeural`, `EmmaNeural`, `JennyNeural`) or add a comma/hyphen pause for tricky compound terms, then verify by watching `final_short.mp4` with audio via `read_file`. |
| `CAPTION_OVERLAP` | Re-generate captions with `tts_and_captions_v2.py` (exact `WordBoundary` clamping) or `srt_to_ass.py` (strict `next_start - 0.01s` clamp) so `assemble_short.sh`'s overlap assertion passes. | Inspect offending timestamps printed by `assemble_short.sh` and adjust overlapping SRT cue boundaries before regenerating `.ass`. |
| `CAPTION_CLIP_HORIZONTAL` | Regenerate captions with v3.1 Fun Kinetic defaults: `python3 scripts/tts_and_captions_v2.py --caption-style kinetic_keyword --font-size 86 --max-chars 18 --margin-v 420 --keyword-color auto` (or `srt_to_ass.py --font-size 86 --max-chars 18 --margin-v 420 --keyword-color auto`) so every 2-3 word chunk keeps ~45-50px margins at peak `126%` pop + `+/-2.5 deg` tilt. | Split extra-long compound phrases or hyphenated words in `shot_plan.json` dialogue (or lower `--font-size` slightly) so no line exceeds `18-20` characters, then re-synthesize captions. |
| `AUDIO_DESYNC` | Switch to **Audio-First Timing**: run `tts_and_captions_v2.py` first to generate `shot_timings.json`, then animate every Mode B shot to its exact spoken duration (`animate_shot_v2.py --timings`). For Mode A native audio, re-run edit with `--strip-audio`. | Trim or pad clip boundaries by 0.05-0.15s before concat, and inspect `f_end.png` via `extract_qa_frames.sh` (uses video-stream duration + `-sseof`). |
| `OFF_MODEL_CHARACTER` / `LIKENESS_DRIFT` | Run Stage 0 `python3 scripts/research_characters.py --entities "..."` (or `--user-ref <id>=<local_image_path>` for official mascots/photos), visually inspect the real reference image via `read_file`, regenerate the 3-panel turnaround sheet using Template 1B (mascot) or Template 1C (real person), verify side-by-side against the Stage 0 reference, and re-anchor all Stage 3 shots to the locked sheet. | If direct photo-to-image triggers a celebrity filter, inspect the Stage 0 portrait visually, encode exact observable traits (hairline/color, glasses, facial structure, age, signature jacket/attire) in Template 1C without uploading the raw photo, approve the 3-panel sheet side-by-side, and pass only that sheet to Stage 3. |
| `SOLO_CHAR_BLEED` | Prepend the explicit solo-character override clause to the shot prompt (`"SOLO character: ONLY <char> appears in this frame; no other characters, mascots, or co-hosts appear anywhere in the scene"`) and pass ONLY that character's turnaround sheet in the reference image array. | Remove any mention of secondary characters or channel hosts from `style_bible` (keep `style_bible` purely rendering/lighting/framing) and re-roll the shot. |
| `BGM_OVERPOWERS_VO` | Re-run assembly with vocal clarity EQ enabled and a lower speech-carved BGM bed: `SHORTS_VO_CLARITY=1 SHORTS_BGM_GAIN_DB=-16 bash scripts/assemble_short.sh ...` (drop to `-18` or `-20` dB if BGM is dense), applying 2-4 kHz presence carve + sidechain ducking under VO. | Swap to a sparser instrumental track with fewer mid-range lead melodies (via `retrieve_music.py` or `make_bgm.py`) and re-verify by watching `final_short.mp4` with audio. |
| `BGM_TONE_MISMATCH` | Replace quirky/arcade BGM with a genre-matched dramatic instrumental: run `python3 scripts/retrieve_music.py --mood dramatic_news --duration <sec> --out audio/bgm.wav` (or `--mood cinematic_tension`) and re-assemble. | If offline or no retrieved track fits, synthesize a dark news/tension bed via `python3 scripts/make_bgm.py --mood dramatic_news` (or `--mood cinematic_tension`) and re-assemble with `SHORTS_BGM_GAIN_DB=-16`. |
